## `<jni>`

jni: native methods for Android and desktop JVMs, written in Eskiu.

  import `<jni>`;

  // static native int add(int a, int b);  in class com.example.Calc
  int Java_com_example_Calc_add(*void env, *void cls, int a, int b) { return a + b; }

A native method receives the JNIEnv pointer as its first argument; wrap it in a JniEnv
(`JniEnv e = jni_env(env);`) to call back into the VM. Strings cross as real UTF-8 (the
conversion goes through UTF-16, not JNI's modified UTF-8), lookups that can fail return
a Result and clear the Java exception they raise, and every call of the JNI tables is
also available as-is in `<jni/raw>`.
